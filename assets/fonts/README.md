# Fonts

Self-hosted so visitors' browsers make no third-party requests.

- `inter-latin.woff2`: Inter (variable, weights 400-700, Latin subset). SIL Open Font License 1.1. Source: Google Fonts.
- `material-symbols.woff2`: Material Symbols Outlined, subset to the icons the site uses. Apache License 2.0. Source: Google Fonts.

If a page needs a new icon, regenerate the subset with that icon name added (the file only contains the icons listed in the Google Fonts request used to build it, which are: accessibility_new, add_location_alt, arrow_forward, dark_mode, edit_note, explore, groups, handshake, light_mode, mail, map, route, school, share, smartphone, travel_explore).
